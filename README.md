Guia das Insígnias – Desafios de Lógica e Programação

Este projeto contém uma série de desafios para desenvolver lógica de programação, estruturas de dados, loops, condicionais e pensamento lógico, pensados para adolescentes e iniciantes.

1. Insígnia da Lógica – Floresta da Lógica

Desafio: Descobrir uma sequência lógica e encontrar a letra final "Na".

Objetivo: Desenvolver raciocínio lógico, percepção de padrões e sequência de passos.

Como funciona no código: Python percorre o alfabeto e verifica critérios ocultos para imprimir a letra correta.

Dica: Observe os padrões que aparecem na sequência e como as letras são selecionadas.

2. Insígnia de Algoritmos – Torre dos Algoritmos

Desafio: Criar um algoritmo que gera a letra "S" seguindo regras ocultas.

Objetivo: Trabalhar lógica de sequência de passos e pensamento estruturado.

Como funciona no código: Python percorre arrays e aplica condições para descobrir a letra secreta.

Dica: Preste atenção aos filtros aplicados na sequência para entender a seleção final.

3. Insígnia de Estruturas de Dados – Caverna das Estruturas

Desafio: Resolver um problema com listas/filas e encontrar "A".

Objetivo: Compreender manipulação de dados em estruturas simples e raciocínio sequencial.

Como funciona no código: Python simula uma fila, adicionando e removendo elementos; o primeiro elemento é a resposta.

Dica: Pense como filas e pilhas funcionam: FIFO (fila) ou LIFO (pilha).

4. Insígnia de Debug – Vale dos Bugs

Desafio: Corrigir erros em loops e descobrir "L".

Objetivo: Desenvolver atenção a detalhes e lógica aplicada à programação.

Como funciona no código: Python contém um loop com erro; ao corrigir, a letra correta é exibida.

Dica: Leia cada passo do código cuidadosamente e teste mentalmente cada operação.

5. Insígnia de Condicionais – Planícies If/Else

Desafio: Analisar condições para determinar "A".

Objetivo: Ensinar lógica condicional de forma prática.

Como funciona no código: Python avalia várias condições (if/else) e apenas uma leva à resposta.

Dica: Observe todas as condições e identifique qual se aplica primeiro ao cenário.

6. Insígnia de Sequências e Loops – Montanhas do Loop

Desafio: Criar padrões de repetição e encontrar "N".

Objetivo: Introduzir conceitos de repetição e loops de forma visual.

Como funciona no código: JavaScript percorre números/letras e aplica substituições para revelar a letra.

Dica: Observe o padrão do loop e os critérios de substituição.

7. Insígnia de Criptografia – Castelo Codificado

Desafio: Decifrar mensagem; saída final é "pegadinha" (pegadinha!).

Objetivo: Desenvolver raciocínio lógico e perceber armadilhas em códigos.

Como funciona no código: Python/JS simula decodificação com loops e chr(), formando "pegadinha" de forma camuflada.

Dica: Nem tudo precisa ser decodificado; preste atenção ao resultado final inesperado.

8. Insígnia de Padrões e Arrays – Deserto dos Arrays

Desafio: Descobrir o elemento faltante e encontrar "lab 4".

Objetivo: Trabalhar percepção de padrões e manipulação de arrays.

Como funciona no código: JavaScript preenche o elemento null usando o número do elemento anterior para gerar "lab 4".

Dica: Analise o padrão "lab X" e use o número anterior para descobrir o elemento faltante.
